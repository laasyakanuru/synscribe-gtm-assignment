# Segment funnel: MNCs with a Singapore marketing team

Deterministic: same inputs + same CONFIG + same seed = same lists, same sample, same numbers.

## Run

```
pip install pandas
python funnel.py download   # 27 ACRA CSVs from data.gov.sg -> data/acra/ (~690 MB)
python funnel.py profile    # confirm entity-type/status strings, edit CONFIG if they differ
python funnel.py build      # stages 1-5 -> out/
# fill out/05_linkedin_checks_TO_FILL.csv by hand (LinkedIn, ~2-3 min/company)
python funnel.py estimate   # -> out/estimate.md
# work the outbound list top-down, fill its tracking columns
python funnel.py outcomes   # -> out/outcomes.md (reply rate, single-seat vs team asks, by segment)
```

If `download` fails, download the CSVs manually from the "ACRA Information on Corporate
Entities" collection on data.gov.sg into `data/acra/`.

## The funnel

| Stage | Rule | Output | Deterministic? |
|---|---|---|---|
| 0 | Full ACRA register | - | Yes |
| 1 | Live local companies + live foreign-company branches | 01_live_companies.csv | Yes |
| 2a | Entity name contains an alias of a company in `data/frame.csv` (whole-word) | 02_multinational_entities.csv | Yes, given the frame |
| 2b | Registered foreign-company branch (multinational by definition) | same file | Yes |
| 3 | Drop SSIC: advertising, market research, public admin, education, membership orgs | 03_excluded.csv | Yes |
| 4 | Collapse to one row per company group; tag HQ | 04_candidate_companies.csv | Yes |
| 5 | Mid-size companies for LinkedIn checks (all, or a seeded sample if > 150) | 05_linkedin_checks_TO_FILL.csv | Yes |
| 5b | Outbound order built from the checks | 06_outbound_order.csv | Yes |
| 6 | Checks 2-3 (6+ SG marketers, a leader) on LinkedIn | filled by hand | No: no public dataset |
| 7 | Pass rate (Wilson 95% CI) x pool size per stratum | estimate.md | Yes |

## The frame (`data/frame.csv`)

One row per parent company. You choose the source and record it in `frame_source`.

```
parent_name,aliases,hq_country,frame_source
Alphabet,Google;YouTube,United States,Forbes Global 2000 (2026)
DBS Group,DBS Bank,Singapore,SGX listing
```

`aliases` = the names the Singapore entities trade under, separated by `;`. Single-word
aliases are flagged `needs_review` because they can match unrelated firms.

## Known limits

- **Coverage:** a foreign-owned local subsidiary is only found if its parent is in the frame.
  ACRA open data has no parent-company field, so the result undercounts mid-size MNCs.
- **Headcount:** no public dataset gives marketing headcount by company and location.
  Stage 6 is manual; the sample size sets the confidence interval.
- **SSIC prefixes and status strings** are set in CONFIG; verify them before relying on the output.
- LinkedIn is checked by hand, not scraped.

## Frame, segments and outbound order (added 2026-09-28)

`data/frame.csv` is generated by `data/frame_build/build_frame.py` (run it from that folder).
Inputs there: `cmc_top1000_raw.txt`, `cmc_1001_1500_raw.txt` (companiesmarketcap.com),
`supplement.txt` (hand-curated private/smaller multinationals), `midsize_sources.txt`
(SGX mid-caps + a PARTIAL FT High-Growth Asia-Pacific list).

Extra frame columns:

| column | meaning |
|---|---|
| `global_tier` | y = in Forbes Global 2000. Until `forbes_global2000.txt` (one name per line) is added to `data/frame_build/`, a proxy is used: market-cap top 1500. See `global_tier_basis`. |
| `size_segment` | `large` or `mid`. Anything with global_tier = y is `large`. |
| `mnc_basis` | Why a Singapore-HQ company counts as multinational. "Pending" = confirm at the LinkedIn check (c1). |
| `listed_in_midsize_source` | y = appears in the SGX mid-cap or FT high-growth list. |

Alias rules: an alias must start the ACRA entity name. `=Word` (and any auto-derived single
word or alias of 3 letters or fewer) is strict: every other word in the entity name must be neutral
(`CONFIG["neutral_tokens"]`) or part of the parent's own names. Uncertain matches go to
`out/02_frame_review.csv`; per-parent status is in `out/02_frame_parents.csv`.

### Scope: mid-size only (decided 2026-09-28)

Only `size_segment = mid` companies are researched and contacted (`CONFIG["research_segments"]`).
Large companies stay in `04_candidate_companies.csv` for reference; nothing else uses them.

1. `05_linkedin_checks_TO_FILL.csv` — the only place LinkedIn checks are done. It holds every
   mid-size candidate (census) while the pool is 150 or fewer (`census_max`); above that it
   switches to a seeded sample of `sample_per_cell` per industry group. Checks added:
   `linkedin_company_size` and `c0_midsize_confirmed(y/n)`.
   A company passes if c0 = y, c1 = y, c2 >= 6, c3 >= 1 and it is not excluded on review.
2. `06_outbound_order.csv` — built from 05. `status`: 1 ready (passed), 2 not yet checked,
   3 excluded (failed). Contact ready rows top-down: Singapore leader decides first, then
   Singapore HQ, then seeded random. Key check results are copied in read-only; edit them in 05.
3. `estimate` — checked companies are counted exactly; only unchecked ones are estimated.
4. `outcomes` — reply rate and single-seat share overall, and by leader-decides, HQ and industry.

Rebuilding keeps everything typed into 05 (check columns) and 06 (outreach columns).

Mid-size definition: 200-5,000 employees worldwide, operating in at least two countries.
`data/prescreen.csv` pre-screens each mid-size company against it (pass / unsure / fail, with a
reason and source; most headcounts are estimates). Fails are left out of 05 and 06 entirely and
listed in `out/05b_prescreen_excluded.csv`; 05 lists passes before "unsure". To bring a company
back, change its row in `data/prescreen.csv`. `estimate` counts pre-screen fails as not qualifying.

Filter 2 (secretarial address) no longer removes entities matched to the frame
(`secretarial_filter_applies_to_frame_matches: False`). Many real multinationals register all
their Singapore entities at a corporate secretary's address (Airwallex, Freshworks, Sprinklr...).
They are flagged in `all_entities_at_secretarial_address` in 04; real presence is tested by the
LinkedIn check (6+ marketers in Singapore). The filter still applies to unframed branches.

Known limits of this version:
- The mid-size pool is small (35 candidates), so the estimate is a lower bound because the full FT list and a full SGX list could
  not be downloaded. Paste the FT list into `data/frame_build/ft_high_growth_apac_full.txt`
  (format `name|country|ft_hg_apac|aliases`) and re-run build_frame.py, then build.
- Name matching still lets through some false positives (roughly 1 in 10 in a spot check, e.g.
  a local "Dollar Tree Inc Pte Ltd"). The LinkedIn check (c1) is where these are removed.
- Foreign branches of companies not in the frame (about 1,600) are set aside in
  `out/02_unframed_branches.csv`. Many are mid-size foreign firms; set
  `require_frame_match: False` to bring them back as segment `unclassified`.
